# Moriaty 书斋首屏重设计

## 最新修订：个人网站全景首页

用户最新要求覆盖下方旧版书斋方案：首屏命名为 Moriaty / Personal Website，移除 Private Study 身份。原画经内置 image_gen 工具横向扩展为本地 `assets/moriaty-panorama-v1.png`，铺满首屏；原图保留。文案改为“对世界保持好奇 / 对真理不懈追求 / 对生活永远热爱”，桌面和移动端均显示。Library 左右切换箭头从 fixed 改为所属 `.site-stage` 内的 absolute 定位，Library 遮罩同步限定在该区域。生成提示词保存在 `assets/moriaty-panorama-v1.prompt.md`。

本设计依据用户对首版截图的修订要求，替代之前的视频 Hero 方案。

- 使用已有原始角色图 `assets/moriaty-character.png` 作为中央主视觉，不使用用户反馈截图作为网页素材。
- 删除外部视频、外部字体、英文营销式大标题、胶囊玻璃按钮和原模板导航。
- 与后两页共享纯黑底色、哑光黄铜、暖灰文字、Georgia / 仿宋字体、细线、宽字距和统一 wordmark。
- 桌面中央展示角色及原画中的星盘、古典雕像与书籍，两侧留出身份文字和两个章节入口。
- 左侧身份为 MORIATY / 观照 · 思辨 · 留存；右侧入口分别前往藏书馆与思维树。
- 移动端保留主视觉，身份文字和双入口顺序排列在其下方。
- 原图文件保持不变，使用 CSS 边缘淡化融入黑色背景。
- 本次修改在项目根目录完成。旧 worktree 是上一版快照，不作为当前交付入口。

验证范围：JavaScript 语法、静态锚点和资源引用、旧模板残留检查。此前浏览器工具拒绝本地文件访问，因此本轮不声称已通过浏览器视觉验收。
