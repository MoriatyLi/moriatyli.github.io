# Moriaty Library 首页设计规格

**日期：** 2026-09-26  
**依据：** `Moriaty_Library_完整设计规划_v1.1.md`  
**状态：** 用户已指示开始实现

## 目标

设计并实现 Moriaty Library 的第一版可交互本地网站，让访客直观感受到“黑色宇宙中的六边形思想图书馆”，并能在六个主题书架间探索和阅读文章。`Ariticle_written/` 中的文章可用于网站，但明确排除 `数聚新潮——医疗健康合成数据交易的经纪商培育创业模式.md`（标题为“计划书.docx”）；已删除的文件不会恢复或导入。

## 设计方向

- 主背景使用纯黑 `#000000`，以星点、星座名称、弧线和连线构成星图；下方延伸出低亮度的透视地面网格、金色纹路和多重椭圆环构成的魔法阵，不叠加星云或彩色渐变。
- 六个主题书架围绕观察者组成六边形。每面书架表现为完整立式胡桃木柜，正面为矩形，正背面之间用有实际深度的左右侧板、顶板和底板连续接合；柜内有独立木质背板，书格不能透出星空或地面。柜顶饰条、承书层板和底座形成完整轮廓；六个立柜随视角旋转，远侧立柜显示木质背板，转至前方时显示主题书架正面。深胡桃木使用暖铜金边缘光，分类牌使用低饱和黄铜色；避免霓虹和玻璃拟态。
- 桌面首页在浏览器 100% 缩放时，以原页面约 67% 的视觉尺寸呈现。六个柜体放在留有空隙的环形位置，后排柜体略高于前排，空出的地面可见金色纹路与魔法阵。窄屏保持可操作的原生尺寸。
- 书籍使用固定种子生成的低饱和色板、不同厚度与纵向书脊标题。书脊采用较清晰的仿宋字形，拉丁文字顺书脊方向排版；分类牌使用克制的衬线字与哑光黄铜色。相同书目在每次渲染中保持视觉一致。
- 首页标识为 `MORIATY LIBRARY`，副标题为 `Archive of Thought`；右上保留 `SEARCH` 与 `INDEX` 入口。底部显示当前书架名称、中文释义和六面位置指示。

## 首页布局与交互

1. 星空作为背景层；六边形书架与书籍居中，当前书架最清晰，其他书架按空间距离弱化。
2. 鼠标可从柜体或书脊按下横向拖动；轻点书脊仍查看书籍信息。触控板水平滑动、左右方向键和页面两侧的金色箭头也可切换相邻书架；按住鼠标向左拖时柜体也向左转。六个书架首尾相接并沿当前方向连续旋转，松开拖动后吸附至最近的 60 度位置。
3. 聚焦或悬停书籍时，书脊轻微前移并提亮，同时在书旁出现图书索引卡。点击书脊固定鼠标旁的信息卡，显示书名、主题、摘要、年份、字数和阅读时长。
4. 点击信息卡的“阅读文章”或再次点击同一本书时，在阅读视图打开真实文章正文，并能返回原书架。
5. Search 与 Index 使用从已确认 Markdown 文件生成的本地目录，支持全文搜索，并可按分类、标签、年份和文章类型筛选。

## 响应式与无障碍

- 桌面端展示明显空间纵深；窄屏降低透视并突出当前书架，以横向 Swipe 或显式按钮切换。
- 所有书籍和导航入口可通过 Tab 聚焦、Enter 激活；左右方向键切换书架，Escape 关闭浮层。
- 为交互元素提供可读名称、明显焦点样式和足够对比度；当前书架状态同时以文字标示，不只依赖颜色。
- 遵循 `prefers-reduced-motion: reduce`：弱化或移除旋转、惯性和抽书动画，改用即时切换或轻淡入效果。

## 内容与名称治理

- 网站从 `Ariticle_written/*.md` 生成本地目录，遵守生成脚本中的明确排除名单；其他位置和已删除文件不得自动扫描。
- 原始文件名与正文保持原样作为来源记录；网页展示标题经过 Unicode NFC、导出后缀/Notion ID 清理和空白规整。书脊标题使用统一长度的摘要，目录和阅读视图中的长标题自然换行，不溢出布局。
- 不能可靠修复的乱码标题进入复核名单，不猜写替代文字。
- 稳定书籍 ID 与规范标题分开保存；标题碰撞时明确区分，不覆盖正文。
- 分类和标签来自可编辑的本地生成规则；生成规则不替代未来公开部署所需的隐私审核和发布确认。

## 本阶段不包含

数据库、CMS、账号体系、云端 API、评论/点赞、文章关联星图、WebGL 和外部 3D 模型。立柜结构由 HTML/CSS 3D 面板组成。首页装饰星图不映射文章内容。网站应能作为本地静态文件打开；不上传或发布到远程服务。

## 验收标准

- 首页视觉符合纯黑宇宙、带有星座连线的克制星图、留有柜体间距的六面立柜、金色地面纹路与魔法阵的方向。
- 六个分类构成可理解的六边形；支持拖动/滑动、键盘和按钮切换，并吸附至六个书架位置。
- 书籍悬停/聚焦时信息卡内容清晰；书目颜色和布局在重复渲染中稳定。
- 窄屏可浏览当前书架并切换；减少动态效果偏好得到尊重。
- Search、Index、书籍均为可识别且可聚焦的控件。
- 页面中只出现虚构书目，没有从未经审核的私人文章素材导入的信息。
