# Moriaty Library 首页设计规格

**日期：** 2026-09-26  
**依据：** `Moriaty_Library_完整设计规划_v1.1.md`  
**状态：** 待用户审阅

## 目标

设计并实现 Moriaty Library 的第一张可交互首页，让访客直观感受到“黑色宇宙中的六边形思想图书馆”，并能在六个主题书架间探索。该阶段只使用虚构书名和合成书目数据；现有文章素材在完成隐私审查与公开白名单之前，不进入网站、搜索索引或预览数据。

## 设计方向

- 主背景使用纯黑 `#000000`，以低亮度星点和极淡星图作为环境层，确保书架与文字仍是视觉焦点。
- 六个主题书架围绕观察者组成六边形。书架以深胡桃木呈现，分类牌使用低饱和黄铜色；避免霓虹、玻璃拟态和过强的 3D 装饰。
- 书籍使用固定种子生成的克制色板、不同厚度与纵向书脊标题。相同书目在每次渲染中保持视觉一致。
- 首页标识为 `MORIATY LIBRARY`，副标题为 `Archive of Thought`；右上保留 `SEARCH` 与 `INDEX` 入口。底部显示当前书架名称、中文释义和六面位置指示。

## 首页布局与交互

1. 星空作为背景层；六边形书架与书籍居中，当前书架最清晰，其他书架按空间距离弱化。
2. 鼠标横向拖动、触控板水平滑动、左右方向键和屏幕上的左右按钮都可旋转书架；松开后吸附至最近的 60 度位置。
3. 聚焦或悬停书籍时，书脊轻微前移并提亮，同时出现仿旧图书索引卡，显示虚构书名、主题、年份、标签和阅读时长。
4. 激活书籍时进入该书的阅读页面或预览状态。首页原型使用最少量的虚构内容验证这一衔接；真实文章阅读器与导入流程不属于本阶段。
5. Search 与 Index 是清晰可操作的入口。此阶段可提供空状态或使用同一组合成数据的轻量面板，不连接真实文章，也不宣称拥有未经审核的实际藏书数量。

## 响应式与无障碍

- 桌面端展示明显空间纵深；窄屏降低透视并突出当前书架，以横向 Swipe 或显式按钮切换。
- 所有书籍和导航入口可通过 Tab 聚焦、Enter 激活；左右方向键切换书架，Escape 关闭浮层。
- 为交互元素提供可读名称、明显焦点样式和足够对比度；当前书架状态同时以文字标示，不只依赖颜色。
- 遵循 `prefers-reduced-motion: reduce`：弱化或移除旋转、惯性和抽书动画，改用即时切换或轻淡入效果。

## 内容与隐私边界

- 首页开发数据必须是明确虚构的书目，不从 `Ariticle_written` 目录自动扫描、导入或摘录内容。
- 页面不展示由未审核素材推导的书名、摘要、标签、统计、搜索结果或路径。
- 之后接入内容前，必须先完成规划中的隐私审查、公开白名单、重复/版本处理和人工发布确认。

## 本阶段不包含

真实文章导入或发布、数据库、CMS、账号体系、生产搜索、生产 Index、完整文章阅读器、文章星图、评论/点赞、真实 3D/WebGL。首页入口可以为后续页面留出明确位置，但不模拟这些功能已经上线。

## 验收标准

- 首页视觉符合纯黑宇宙、克制星图、胡桃木和低饱和黄铜的方向。
- 六个分类构成可理解的六边形；支持拖动/滑动、键盘和按钮切换，并吸附至六个书架位置。
- 书籍悬停/聚焦时信息卡内容清晰；书目颜色和布局在重复渲染中稳定。
- 窄屏可浏览当前书架并切换；减少动态效果偏好得到尊重。
- Search、Index、书籍均为可识别且可聚焦的控件。
- 页面中只出现虚构书目，没有从未经审核的私人文章素材导入的信息。
