# 2026中国女性主义运动报告

作品状态: 完成
作者: Li Moriaty
发布日期: 2026年2月12日
类别: 社会科学

一、前言

        女性主义运动起源于18世纪末至19世纪初的西方社会,当时女性开始有组织地争取平等权利。这一运动通常被划分为几个历史阶段,每个阶段都有其特定的关注点和诉求。

        第一波女性主义主要集中在争取法律权利,特别是选举权。1848年在美国纽约州塞内卡福尔斯举行的女权大会标志着有组织女权运动的开端。这一时期的代表人物包括苏珊·安东尼、伊丽莎白·斯坦顿等,她们为女性争取投票权、财产权和受教育权而奋斗。第二波女性主义将关注点扩展到更广泛的社会平等议题,包括职场歧视、生育权、家庭暴力等。西蒙·德·波伏娃的《第二性》(1949年)和贝蒂·弗里丹的《女性的奥秘》(1963年)成为这一时期的重要理论著作,深刻影响了全球女性主义运动的发展。第三波女性主义强调多元性和包容性，关注不同种族、阶级、性取向女性的具体经验。这一阶段的女性主义更加注重个体差异和交叉性理论，反对单一的女性主义叙事。

        在漫长的历史演进过程中，女性主义的深入发展贯穿了资本主义社会的始终，极大程度地推动了社会法制的完善和人类文明的进步，成为当今时代最具广泛影响力的思想潮流之一。在女性主义的演变历程中，出现过激进女权主义、自由主义女权主义、马克思主义女权主义和后现代与解构主义女权主义，也先后涌现出一批敢想敢做、满怀抱负、成就卓著的以女性主义理论为纲领的社会活动者。由此看来，女性主义和女性主义活动者们有着不可磨灭的伟大历史成就及时代意义。

        中国的女性主义运动始于20世纪初的新文化运动时期。五四运动期间，女性解放成为重要议题，出现了"妇女解放"、"男女平等"等口号。20世纪20年代，中国共产党将妇女解放纳入革命纲领。新中国成立后，妇女在法律上获得了平等地位，但社会性别平等仍面临诸多挑战。

         随着二十一世纪以来，新媒介技术不断丰富以及传播形式日趋多样，女性主义得到了更加充分的发展。但是随着权威舆论的缺位问题出现，本就牵涉广泛并且极易引起共鸣的女性主义成为了率先出现话语权下放的思潮之一，并且进一步诱导了叙事结构的异化和改变。本报告旨在探讨由此产生的一系列社会问题，实现追本溯源、正本清源、立本开源三条路径的问题探讨，实现女性主义的长期、可持续发展，让女性主义在二十一世纪保持和发扬其历史影响力。

二、根本原因

        在人类社会进入工业文明以来，物质基础极大丰富，进而对原有的以家庭为基本单位的社会组织形式形成了强烈冲击。人们不再需要依托于家庭的“避风港”作用作为自身抵御社会系统性风险的社会组织，而是可以以自身个体为基本单位来作为风险平衡的单位。随着家庭这一组织结构的功能不断弱化，政治上无法回答“家庭作为社会组织要求个体承担的义务个体是否能拒绝”以及“家庭作为社会组织要求个体放弃的权利个体是否能争取”。正是在这样的背景下，女性主义思潮应运而生。

         进一步的来理解，女性主义思潮在中国的发展过程中，由于社会转型期的特殊性，呈现出与西方相似但有区别的演进路径。

         改革开放以来，中国社会经历了从计划经济向市场经济的转变，这一转变对女性的社会地位产生了复杂而深远的影响。一方面,市场经济为女性提供了更多的就业机会和经济独立的可能性；另一方面，传统的性别观念在市场化进程中出现了某种程度的回潮，职场性别歧视、婚姻家庭中的不平等现象依然存在。

         进入21世纪后，互联网特别是社交媒体的兴起,为女性主义话语的传播提供了新的平台。微博、微信等社交媒体成为女性表达诉求、组织行动的重要工具。西方女性主义运动在中国的传播、针对性别暴力的公开讨论、对职场性别歧视的揭露等，都显示出新媒体时代女性主义运动的新特点。然而，正是在这个过程中，女性主义话语开始出现分化和异化的现象。

三、三种错误的女权主义思想

（一）极端女性主义

         极端女性主义，在女性主义运动过程中看，将一般性的社会性议题武断地理解为一种性别叙事视角下的议题，或者是忽略掉社会或个体的阶段性和成长性，主张以一蹴而就的变革替代辩证否定的改革；在女性主义运动的结果上看，在社会生活中提出的女性主义主张构成了社会的不稳定性因素，但是没有实质性提升女性的权利或权益。

         要正确认识极端女性主义的危害，就要用发展和联系的眼光来看这一问题。极端女性主义的发展构成了对社会平衡结构的无序、异常、猛烈的冲击，不符合社会发展循序渐进的变革格局，势必会招致社会上一种抵制的社会氛围。同时，由于社会缺乏对于女性主义与极端女性主义的认识和界定，这样的社会氛围可能会难以分辨女性主义发展的健康与否，使得以政府为主体、社会群众广泛参与的社会调节机制过分判断女性主义发展的状态。随着这一链条的传导，女性主义发展的过程必然受到非常严重的遏制和阻力。

（二）空想女性主义

         空想女性主义是指，在女性主义运动过程中，主张过分追求或者只追求意识形态的平等而实际忽略权利及义务的平等的女性主义者。政治学观点上一般认为思想/理论是社会变革的先导，但是将这一句话视作空想女性主义的遮羞布也未免太过单纯。

         从形式上看，诸如“金主妈妈”“老天奶”等所谓的“女性主义”话语体系已经对当前的语言系统造成了一定程度的冲击；从内容上看，这样的话语体系在底层逻辑和意识形态上确切地强调了女性在社会历史中与男性同等的历史主体作用。作为一种对于原有语言体系的修正的尝试是具备相当积极意义的，但是要理解这一问题的根本首先要回归到语言的本质的层面。

          语言是人类最重要的交际工具和思维工具。它不仅可以描述客观事物，还可以表达主观感受和抽象概念。语言是由词汇材料和语法规则构成的音义结合的符号系统。语言作为一种符号系统，其在社会交往过程中发挥的作用可以近似类比于货币在市场行为中发挥的作用。换言之，语言本身其实不具备任何意思表示，而是基于广泛的社会契约形成的一套约定俗成的符号系统，其形成的意义本身也就是为了便于社会交往和人员流动。因此，割裂的女性主义话语体系不仅背离了语言的初衷，更是没有在社会层面达成其争取意识形态高地的主张，最重要的是没有拓展在当代中国社会环境下女性主义争取权利平等的实质边界。

         空想女性主义最需要警惕的就是一种“阿Q”式的胜利。这样的精神胜利法会使得更多的女性主义者错误地判断当前女性主义运动的形势，从而影响后续女性主义的持续健康的发展。

（三）去结构女性主义

          去结构女性主义是指将女性视为社会结构中的独立群体，进而片面地将女性与社会中的其他群体视作对立或者竞争的关系的女性主义思潮。这样的观点暴露出了开展当前的女性主义运动的群体中存在众多社会运动经验不足、当前形势判断失误、未来纲领规划不清晰的社会活动者。

         一场广泛的社会运动想要取得胜利，就一定要团结一切可以团结的积极因素，发动真正的群众力量开展活动。而去结构女性主义者们将女性圈入孤立无援的怪圈，在根本上动摇着女性主义运动取得胜利的根基。

         与此同时，尚不能排除去结构女性主义者的背后是否有资本的操弄。资本企图利用女性在社会结构中的“不安全心理”进一步制造焦虑情结，来满足其扩充消费的目的，一如曾经的“容貌焦虑”“安全焦虑”等等。

四、流派之争

         对于一场社会运动而言，最需要提防的问题就是流派之争，当前的女性主义运动同样面临着相同的困境。在2024-2025年间，中文互联网上一度出现了关于“自然女权”和“传统女权”之争。

         所谓“自然女权” 的核心主张就是“去除了社会修饰的女性，才是自然的女性”，她们认为，长发、化妆、高跟鞋、裙子、美甲、脱毛等“女性化”特征，并非女性天生喜欢，而是父权社会强加给女性的枷锁（即“服美役”）。只有彻底抛弃这些“取悦男性”或“自我客体化”的修饰，回归生理原本的“自然状态”，才是真正的女权觉醒。她们往往持有激进的分离主义立场（6B4T：不婚、不育、不恋、不性等）。“传统女权“的核心主张就是“女权是选择的自由”。她们认为，女性解放意味着拥有选择权——既可以选择素颜短发，也可以选择化妆长发。只要是女性出于自我意志的选择，都应被尊重。她们反对用一套新的严苛标准（必须剪短发、不准化妆）来取代旧的枷锁。她们认为“自然女权”是在搞教条主义和霸凌，剥夺了女性爱美的权利。

         对于这场运动的成因尚不明了，但是核心争议基本上就在于任何一个女性主义者都绕不开去的问题”女性主义者应不应该服美役“。当前的女性主义者无法一致地回答这样的问题，一方面是因为女性主义运动缺乏统一且达成广泛共识地纲领，另一方面就是当前女性主义运动的矛头仍然没有合力指向女性主义最根本需要回答的问题——如何更加快速地争取和扩展女性权利的边界。

         对于这样的流派之争，历史上经验性的回答是需要双方基于根本利益达成有效的共识，来规避社会活动群体内部的撕裂和争议，同时将矛头直接指向问题的根基以更稳健的速度取得运动的全面胜利。

五、未来走向

         结合对于女性主义运动的历史意义和发展现状的分析，我们才能够用更加务实的态度和精神来看待女性主义运动的未来走向。

（一）建立统一的运动纲领并达成社会共识

         女性主义运动建立统一纲领并达成广泛社会共识的根本意义，在于将分散、原子化甚至互相对立的个体不满，转化为具有实质政治博弈能力的集体意志，从而避免运动陷入无休止的内部纯洁性审查与“鄙视链”消耗，确保女权主义能从一种亚文化的网络喧嚣升格为推动法律、经济与文化制度变革的严肃社会力量；这要求运动的主导者与参与者必须具备超越激进教条的政治成熟度，在“求同存异”的基础上寻找涵盖不同阶层、地域与文化背景群众的“最大公约数”（如反暴力、就业公平、生育保障等生存权与发展权议题），摒弃以单一审美或生活方式作为准入门槛的排他性逻辑，唯有以包容性的底色连接最广大的普通女性和其他能够团结的群众，才能在对抗结构性压迫的漫长征途中构建起坚不可摧的统一战线。

（二）提防资本主义的利用以及分立分化

          资本主义对女性主义运动最隐蔽且致命的利用，在于它擅长将严肃的政治抗争降格为个性化的“消费选择”，并将集体的阶级意识瓦解为相互敌对的“身份标签”。在资本的逻辑下，女性主义容易被转化为鼓励消费的“粉红税”陷阱，让女性误以为购买力即是权力；而女性主义者们若不警惕，也可能沦为流量经济中贩卖焦虑、收割注意力的另一种商业景观。资本通过算法机制不断放大不同派别在审美和生活方式上的多元对立，诱导女性将精力耗费在“长发还是短发”、“化妆还是素颜”这些表象层面的互搏中。

         这种分化策略的险恶之处在于，它成功地将原本针对父权制和资本剥削的结构性怒火，转移为女性内部的道德审判。只要女性主义的战场被锁定在消费领域（买什么或不买什么），而非生产领域（劳动权益、薪酬分配、财产制度），资本就能在制造分裂的同时坐收渔利，确保女性作为一个整体力量无法形成真正的政治联盟去触动既得利益者的根基。

（三）积极融入阶级斗争的历史洪流

         将女性主义运动积极融入阶级斗争的历史洪流，是打破当前女性主义运动内耗僵局、防止运动被资本主义消费逻辑收编的根本出路；这种融合要求女性主义者必须透过发型、妆容等表象层面的文化争端，直视父权制与私有制共谋的经济根源，深刻认识到女性受压迫的本质不仅是性别身份的贬抑，更是资本对女性再生产劳动（如家务、生育）与廉价劳动力的系统性剥削。只有摒弃那种带有中产阶级精英色彩、仅仅在消费选择与生活方式上做文章的“伪自由”，转而关注广大底层女性最迫切的生存权与发展权，将性别议题从狭隘的身份政治上升为争取同工同酬、社会化抚育与打破阶级固化的宏大叙事，女性主义才能真正团结最广泛的劳动者群体，形成足以撼动结构性不公的政治力量，从而在人类解放的总体进程中实现女性的彻底解放。
