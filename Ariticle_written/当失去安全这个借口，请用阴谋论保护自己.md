# 安全已不再是借口，请用阴谋论保护自己

笔者其实并不是阴谋论的支持者，但是面临着最近接二连三的恶性事件，当这些恶性事件发生的后果是危及生命时，我们不得不拿出阴谋论这样一种底线思维，去计量当下的最坏结果，把握好风险控制，力求对自己生命的最大保护。

相信对于这两件事情热衷于时政的朋友应当有所关注，虽然第一件事似乎热度有所受限，但是中央一号的批示还是将这件事情最终暴露在众人的目光之下。

如果基于阴谋论的观点，我们可以做出三个基本判断：

1. 这两件事情之间有着某种联系，而非个案
2. 这两件事背后有实实在在的推手，比如境外反动势力
3. 这两件事情背后揭示的社会问题具有普遍意义1

有了这三个基本原理，再通过对于这两个案件种种要素的归纳，包括时间、地点、凶手侧写、杀人动机等等，我们就可以开展演绎推理了。

从地点上来说，第一起案件发生在珠三角，第二起发生于长三角，那么依此类推，如果还有第三起案件，最有可能的发生地点就在在京津冀地区。

从发生的时间上来说，考虑到背后的推手，我们就可以充分怀疑存在境外反动势力，如果真的是这样，结合近期国际局势的主流，我们就有充分理由怀疑是否是美国民主党在换届前希望打空手里的“弹药”从而策划与煽动的，一定程度上还能对特朗普政府后续与中国政府的外交关系造成恶性影响。那么请注意：今年的春运时间与美国总统换届时间极其相似，可以在能力范围内尽早回家，避免春运期间人员聚集等不稳定因素的扰动.

从行为与动机来说，无论是“烂赌”的老人还是失业又失意的青年在当前的社会结构中都并非个例，尤其是青年的失业率问题以及所谓的“脱不下的长衫”，这些都不是昙花一现，而是积久而成的社会性问题。

青年的上升通道充足了吗？社会环境友好了吗？十数年的读书生涯值得了吗？社会乱象治理充分了吗？扫黑除恶根治了吗？老年群体的社会保障以及养老问题解决了吗？

在这里我想引用近期几个重要论坛上都有学者提到的观点：究竟是不想做，还是不能做？

最后做个总结，请务必着重关注以下几个方面：

1. 京津冀地区要注意安全，避免人群聚集地区
2. 春运期间要多加小心，尽可能早回
3. 青年员工的就业问题急需关注，这未必不是“莱克星顿的枪声”
4. 社会保障以及养老问题是基础性工作，必须放在首要位置
