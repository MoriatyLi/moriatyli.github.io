# 对于自我的harness engineering

## 关于我把自己调成AI

昨晚闲下来学完Harness Enginerring，今早醒来突然发现我这几年孜孜不倦搞得一项关于“自我”的方法论貌似和harness有异曲同工之妙。以下是“概念-方法论”对照。

1. 仓库即记录系统-对照斯多葛学派的绝对二分法
2. 地图而非手册-对照一套理论化体系化的三观
- 世界观：世界是由物质和意识共同构成的，二者相互决定相互影响，世界万事万物都处在一个回归的均匀连续变化的状态下
- 人生观：人生就是将“自我”放逐到一个又一个具体的事件中去经历和体验，最后再回归到自我
- 价值观：价值是对具体事物的结论性的评判和论证，是一种后置评价。
3. 机械化执行-基于演绎推理的理论框架
4. 智能体可读性-风险控制，整合既有
5. 熵管理-短期的意义后置和长期的年度报告这一类强制性系统回顾
6. 人类掌舵，智能体执行-方法论先行
